# Where is the software?

Evidence-gathering on "if AI coding is so great, where is all the new good software?" (Nate Meyvis, 12 Oct 2026).

- `WRITEUP.md` — **start here**: consolidated blog-ready write-up with all findings and sources
- `reports/00-summary.md` — running summary: synthesis + scorecard vs Nate's hypotheses
- `reports/01-findings-round1.md` — features (PR throughput, AWS), Steam patching, reliability (status pages, Bugzilla), niche registries (NVDA, HACS, Raycast)
- `reports/02-game-hobbyist-catalogue.md` — catalogue of AI-assisted hobbyist ports/decomps/emulators + publisher-side items
- `reports/03-brawlback.md` — Brawlback rollback-netcode timeline (incl. its adoption of AI-built Orca code)
- `reports/04-official-ports.md` — are studios shipping more ports/remasters? (Gematsu, Steam, GOG, Wikidata)
- `data/` raw/derived data; `scripts/` collection scripts (scripts were run from a scratch dir; paths may need adjusting)
- `reports/05-literature-review-raw.md` — literature/studies review (raw agent output)
- `reports/06-external-report-critique.md` — replication + critique of an external AI research record (`reports/external-ai-research-record.html`); adds Show HN score thresholds, F-Droid, Modrinth data
- `reports/07-round3-direct-checks.md` — survival audit, stalled projects, progress meters, usage cohorts (detail in `followup-audit/`, `stalled-projects/`, `progress-meters/`, `usage-cohorts/`)
- `reports/08-niche-usage.md` — usage (not just supply) of new NVDA add-ons and Home Assistant integrations (data in `niche-usage/`)
- `reports/09-niche-usage-round2.md` — usage cohorts for Obsidian, Firefox add-ons (AMO), CRAN, WordPress, OctoPrint, Nexus Mods (detail in `niche-usage/<source>/`; large API caches in `*/cache` and cloned repos can be deleted and re-fetched)
- `reports/09` round 3 appendix — Flathub, Decky Loader, Raycast, Blender Extensions (`niche-usage/{flathub,decky,raycast,blender}/`)
- `reports/10-mainstream-markets.md` — Steam (incl. full-count of early-review hits), Google Play, Chrome Web Store, Atlassian Marketplace (`market-usage/<source>/`)
